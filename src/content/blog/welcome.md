## How posts work

Each post is a Markdown file in `src/content/blog/`. The file name becomes the URL. The front-matter at the top sets the title, description, date, cover image and tags.

> Keep posts factual and verifiable. The same red lines as the rest of the site apply.

- Headings start at `##`
- Images go to `public/img/blog/`
- Remove `draft: true` to publish
