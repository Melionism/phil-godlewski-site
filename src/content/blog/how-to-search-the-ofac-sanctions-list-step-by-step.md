All right, guys, if someone tells you a person or company is "on the list," you can check it yourself in two minutes. OFAC runs a free Sanctions List Search tool that lets anyone search the Specially Designated Nationals (SDN) list and OFAC's other lists by name, address, ID number, program and more [1][2]. The search uses fuzzy matching, so it can show close spellings, which is useful for foreign names but means you'll see possible matches that aren't the same person. OFAC's guidance is simple: if you get a hit, look closer. Is the name an exact or close match? Is the person in the same general area? If there are many similarities, OFAC recommends calling its hotline to verify; if it's clearly a false hit, no verification is needed [2]. For EO 13848, filter by the program tag "ELECTION-EO13848" [3].

Here's the tool, search settings, reading a result, and common errors.

**Quick answer**

- How to search the OFAC sanctions list: use OFAC's free Sanctions List Search [1].
- Filter: program "ELECTION-EO13848" for this order [3].
- Fuzzy matching: shows near matches, not confirmed ones.
- If there's a hit: check details; call OFAC's hotline if unsure [2].

## Search settings

1. **Start with the full name.**
2. **Add country** if known.
3. **Lower the score** to catch spelling variants; raise it to cut noise.
4. **Pick a program** to see everyone under it.

## Reading a result

Open the entry. Look at:

- Program tags, e.g., ELECTION-EO13848 and others.
- Date of birth and nationality.
- Aliases.
- Linked entities.

## Common errors

This isn't a "trust me" thing. This is "verify me."

1. **Same name, different person.** Compare birth date and country [2].
2. **Old screenshot.** The list changes; search it today.
3. **Wrong program.** A person may be listed under a different order.
4. **Assuming it's a crime.** A listing isn't a conviction.
