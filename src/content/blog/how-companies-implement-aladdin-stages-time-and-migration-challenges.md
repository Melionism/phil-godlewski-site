All right, guys, buying Aladdin isn't like installing an app. Aladdin implementation is a long project: data has to move, rules have to be rebuilt, people have to be trained. Even the Bank of Israel's setup "required some system customisation" for its benchmark [1]. BlackRock doesn't publish standard timelines or prices, so any number you see online for Aladdin implementation cost or onboarding time is an estimate, not a fact.

Here are the typical stages, the time and cost factors, data migration and the common difficulties.

**Quick answer**

- Aladdin migration: moving positions, history and rules onto the platform.
- Aladdin onboarding time: depends on firm size; no official standard.
- Aladdin implementation cost: not published by BlackRock.
- Hardest part: data quality and custom rules [1].

## What are the typical stages?

| Stage | What happens |
| --- | --- |
| Scoping | Decide which desks, assets and functions move |
| Data mapping | Match the firm's data to Aladdin's format |
| Configuration | Build benchmarks, rules, reports [1] |
| Parallel run | Run old and new systems side by side |
| Go-live | Switch over and retire old tools |

See [which firms run on Aladdin](/blog/who-uses-blackrock-aladdin/).

## What drives time and cost?

1. **Number of asset classes.** Stocks are easier than private credit.
2. **Custom needs.** Like the Bank of Israel's hybrid benchmark [1].
3. **Old systems to replace.** More of them, more work.
4. **Staff training.**

## What about data migration?

Aladdin's pitch is "a common data language" [2]. Getting there means cleaning years of a firm's data into that one language. I need you to see why that's sticky: once your data lives in one system, leaving gets harder.

## What are the common difficulties?

This isn't a "trust me" thing. This is "verify me." The usual pain points:

1. **Messy data** that doesn't map cleanly.
2. **Rules** that worked in the old system and need rebuilding.
3. **Two systems at once** during the parallel run.
4. **Dependence** on one vendor afterward. BlackRock's 10-K notes clients may later move to standalone or in-house tools [3].
